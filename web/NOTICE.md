# Map data attribution

The globe uses Natural Earth 1:110m land outlines, public-domain vector data.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson

Terms: https://www.naturalearthdata.com/about/terms-of-use/

Downloaded 2026-09-20 UTC. Source SHA-256: `9e0729ee253ca7d7a5c4ae9395fb1902264c5377c52e224d13dd85010e2835d9`. `src/land.json` contains outer-ring coordinates rounded to three decimals. No map tiles or runtime network requests are required. The spacecraft position and contact cycle are synthetic and are not derived from this coastline dataset.
